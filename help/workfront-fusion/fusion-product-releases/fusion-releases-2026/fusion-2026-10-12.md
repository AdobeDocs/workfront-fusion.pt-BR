## Conexões federadas para AWS S3, Azure DevOps e SharePoint

Para facilitar a criação de conexões seguras sem armazenar segredos de longa vida, adicionamos suporte à conexão federada aos conectores AWS S3, Azure DevOps e SharePoint.

Isso permite usar o provedor de identidade da sua organização para autenticar o Workfront Fusion com credenciais temporárias em vez de um segredo do cliente ou outra credencial estática. Ela oferece uma opção de conexão mais segura, mantendo o processo de configuração consistente entre conectores que já usam o Azure AD/Microsoft Entra ID ou provedores de identidade AWS IAM.

Para obter mais informações, consulte:

* [Módulos do AWS S3](/help/workfront-fusion/references/apps-and-modules/third-party-connectors/aws-s3-modules.md)
* [Módulos do Azure DevOps](/help/workfront-fusion/references/apps-and-modules/third-party-connectors/azure-dev-ops.md)
* [Módulos do SharePoint](/help/workfront-fusion/references/apps-and-modules/third-party-connectors/sharepoint-modules.md)
