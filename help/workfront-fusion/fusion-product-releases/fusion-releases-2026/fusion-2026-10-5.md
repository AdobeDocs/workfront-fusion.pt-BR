# Atividade de lançamento do Workfront Fusion: semana de 5 de outubro de 2026

Esta página descreve todas as melhorias feitas no Adobe Workfront Fusion na semana de 5 de outubro de 2026.

Para obter uma lista de todas as alterações recentes, consulte a [atividade de lançamento do Adobe Workfront Fusion](/help/workfront-fusion/fusion-product-releases/fusion-release-activity.md).

Para obter uma lista de correções de erros recentes no Workfront Fusion, consulte a página [Atualizações de manutenção do Workfront](https://experienceleague.adobe.com/pt-br/docs/workfront-known-issues/releases/current-updates) e verifique se há atualizações rotuladas como atualização de manutenção do Workfront Fusion.

## Conector Jira: Novos tipos de conexão de conta de serviço

Para facilitar a criação de conexões Jira que correspondem à forma como sua equipe se autentica, adicionamos dois novos tipos de conexão ao conector Jira: Token de API da conta de serviço e Conta de serviço OAuth 2.

Essas opções permitem criar conexões para automação que devem ser executadas como uma conta de serviço dedicada do Jira em vez de uma conta de usuário pessoal. Use o token da API da conta de serviço quando a conta de serviço Jira for autenticada com um token de API e use o OAuth 2 da conta de serviço quando o ambiente usar o OAuth 2 para a conta de serviço.

Os tipos de conexão Basic e OAuth2 ainda estão disponíveis.

Para obter mais informações, consulte [módulos Jira](/help/workfront-fusion/references/apps-and-modules/third-party-connectors/jira-modules-new.md).

## Novo módulo Criar várias anotações disponível para o conector do Veeva Vault

Para facilitar o uso do módulo Criar várias anotações, ele foi atualizado para um novo módulo. Agora é possível selecionar campos para marcadores, referências e outros campos de anotações antes de fornecer valores, tornando a configuração mais simples e focalizada apenas nos valores priorizados.

O módulo Criar várias anotações disponível anteriormente ainda está disponível, marcado como &quot;Herdado&quot;.

Para obter mais informações sobre os módulos do Veeva Vault, consulte [módulos do Veeva Vault](/help/workfront-fusion/references/apps-and-modules/third-party-connectors/veeva-vault-modules.md).
