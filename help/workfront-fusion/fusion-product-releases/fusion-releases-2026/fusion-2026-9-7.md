# Atividade de lançamento do Workfront Fusion: semana de 7 de setembro de 2026

Esta página descreve todas as melhorias feitas no Adobe Workfront Fusion na semana de 7 de setembro de 2026.

Para obter uma lista de todas as alterações recentes, consulte a [atividade de lançamento do Adobe Workfront Fusion](/help/workfront-fusion/fusion-product-releases/fusion-release-activity.md).

Para obter uma lista de correções de erros recentes no Workfront Fusion, consulte a página [Atualizações de manutenção do Workfront](https://experienceleague.adobe.com/pt-br/docs/workfront-known-issues/releases/current-updates) e verifique se há atualizações rotuladas como atualização de manutenção do Workfront Fusion.

## Novos tipos de autorização para webhooks personalizados

Agora você pode autorizar webhooks personalizados usando dois novos métodos: autenticação de chave de API e assinatura HMAC. A autenticação da chave de API agora é o tipo de autorização padrão para novos webhooks. Os tipos de autorização anteriores ainda estão disponíveis e você pode selecionar o valor vazio para nenhuma autorização.

Para obter mais informações, consulte [Webhooks](/help/workfront-fusion/references/apps-and-modules/universal-connectors/webhooks-updated.md).

## Novo botão Descrever com IA na descrição do cenário

Agora é possível clicar em Descrever com IA no campo de descrição do painel Configurações de um cenário para que a IA gere uma descrição do cenário automaticamente, com base nos módulos e na configuração do cenário.

Para obter mais informações, consulte [Definir configurações de cenário](/help/workfront-fusion/create-scenarios/config-scenarios-settings/configure-scenario-settings.md#description).
