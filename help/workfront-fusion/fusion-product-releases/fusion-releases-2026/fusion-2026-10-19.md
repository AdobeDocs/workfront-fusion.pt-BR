# Atividade de lançamento do Workfront Fusion: semana de 19 de outubro de 2026

Esta página descreve todas as melhorias feitas no Adobe Workfront Fusion na semana de 19 de outubro de 2026.

Para obter uma lista de todas as alterações recentes, consulte a [atividade de lançamento do Adobe Workfront Fusion](/help/workfront-fusion/fusion-product-releases/fusion-release-activity.md).

Para obter uma lista de correções de erros recentes no Workfront Fusion, consulte a página [Atualizações de manutenção do Workfront](https://experienceleague.adobe.com/pt-br/docs/workfront-known-issues/releases/current-updates) e verifique se há atualizações rotuladas como atualização de manutenção do Workfront Fusion.

## Nomes de pool de trabalhadores editáveis

Os proprietários e administradores da organização agora podem renomear os pools de trabalhadores atribuídos à organização. Até agora, cada pool mostrava um nome fixo gerado pelo sistema. Agora você pode dar um nome personalizado a um pool e alterá-lo sempre que precisar.

Para obter mais informações, consulte [Pools de trabalhadores](/help/workfront-fusion/set-up-and-manage-workfront-fusion/licensing-operations-overview/worker-pools.md).

## Novas variáveis de mapeamento

Seis novas variáveis gerais agora estão disponíveis no painel de mapeamento. Eles fornecem links de cenário e execução prontos para uso, URLs de API e identificadores de propriedade, para que você possa incluir esses valores em campos mapeados sem criar URLs ou codificar IDs de equipe e organização.

* `scenarioUrl`: Um link para o cenário atual na interface do usuário do Fusion.
* `executionUrl`: Um link para a execução do cenário atual na interface do usuário do Fusion.
* `scenarioApiUrl`: A URL da API Fusion para o cenário atual.
* `executionApiUrl`: A URL da API Fusion para obter os detalhes da execução atual.
* `teamId`: a ID da equipe do Fusion que possui o cenário atual.
* `organizationId`: A ID da organização do Fusion associada à execução atual.

Essas variáveis estendem as variáveis `executionID`, `scenarioID`, `scenarioName`, `triggerTimestamp` e `operationsConsumed` existentes.

Para obter mais informações, consulte [Funções gerais](/help/workfront-fusion/references/mapping-panel/functions/general-functions.md).

## Alterações no conector Fusion

O conector do Workfront Fusion agora oferece suporte a mais ações para gerenciar sua organização do Fusion de dentro de um cenário.

**Novos módulos e ações**

* **Clonar um registro:** Agora é possível clonar um gancho. Use dependências para mapear as dependências do gancho de origem para o destino, como você faz ao clonar um cenário.
* **Excluir um registro:** Agora é possível excluir uma conexão, um armazenamento de dados, um registro de armazenamento de dados, registros de armazenamento de dados (em massa), uma estrutura de dados, um gancho, uma chave, um cenário ou uma equipe.
* **Listar registros:** Agora é possível listar DLQs, organizações, equipes e usuários.
* **Ler um registro:** Agora você pode ler um DLQ, a organização atual, uma equipe, um usuário ou o usuário autorizado.
* **Obter dependências de registro:** Agora é possível obter as dependências de um gancho.
* **Obter dependentes de registro:** Este novo módulo retorna os dependentes de armazenamentos de dados, ganchos e cenários. Execute-o antes de excluir um recurso para verificar se algo depende dele.

**Outras atualizações**

* Os filtros de propriedade marcados como multivalor agora aceitam valores separados por vírgula com os operadores `==` e `!=`. Atualmente, somente a propriedade `id` nos usuários oferece suporte a isso (por exemplo, `id==123,456`).
* Ao excluir uma fila de gancho, o parâmetro `except` substitui `excludeId` e pode ser usado somente ao excluir todos os itens. O parâmetro `id` agora aceita uma lista separada por vírgulas. Uma nova resposta 423 é retornada quando uma exclusão já está em andamento.
* Ao obter cenários ou um único cenário, agora é possível usar o parâmetro `fields` para escolher quais campos são retornados.

Para obter mais informações, consulte [módulos do Workfront Fusion](/help/workfront-fusion/references/apps-and-modules/adobe-connectors/workfront-fusion-modules.md).

## Conector MCP do Adobe Fusion

O novo conector MCP do Adobe Fusion permite enviar um prompt em linguagem natural para o servidor MCP do Adobe Fusion de dentro de um cenário. Um modelo de linguagem grande (LLM) interpreta sua solicitação e chama as ferramentas do Fusion necessárias para concluí-la.

O conector funciona somente com o endpoint do Adobe Fusion MCP hospedado.

Para obter mais informações, consulte [Módulos MCP do Adobe Fusion](/help/workfront-fusion/references/apps-and-modules/adobe-connectors/adobe-fusion-mcp-modules.md).
