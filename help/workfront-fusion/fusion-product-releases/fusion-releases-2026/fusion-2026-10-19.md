# Atividade de lançamento do Workfront Fusion: semana de 19 de outubro de 2026

Esta página descreve todas as melhorias feitas no Adobe Workfront Fusion na semana de 19 de outubro de 2026.

Para obter uma lista de todas as alterações recentes, consulte a [atividade de lançamento do Adobe Workfront Fusion](/help/workfront-fusion/fusion-product-releases/fusion-release-activity.md).

Para obter uma lista de correções de erros recentes no Workfront Fusion, consulte a página [Atualizações de manutenção do Workfront](https://experienceleague.adobe.com/pt-br/docs/workfront-known-issues/releases/current-updates) e verifique se há atualizações rotuladas como atualização de manutenção do Workfront Fusion.

## Novas variáveis de mapeamento

Seis novas variáveis gerais agora estão disponíveis no painel de mapeamento. Eles fornecem links de cenário e execução prontos para uso, URLs de API e identificadores de propriedade, para que você possa incluir esses valores em campos mapeados sem criar URLs ou codificar IDs de equipe e organização.

* `scenarioUrl`: Um link para o cenário atual na interface do usuário do Fusion.
* `executionUrl`: Um link para a execução do cenário atual na interface do usuário do Fusion.
* `scenarioApiUrl`: A URL da API Fusion para o cenário atual.
* `executionApiUrl`: A URL da API Fusion para obter os detalhes da execução atual.
* `teamId`: a ID da equipe do Fusion que possui o cenário atual.
* `organizationId`: A ID da organização do Fusion associada à execução atual.

Essas variáveis estendem as variáveis `executionID`, `scenarioID`, `scenarioName`, `triggerTimestamp` e `operationsConsumed` existentes.

Para obter mais informações, consulte [Funções gerais](/help/workfront-fusion/references/mapping-panel/functions/general-functions.md).
