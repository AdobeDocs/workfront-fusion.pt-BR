# Exibir histórico de versões do arquivo no Armazenamento

Para obter uma visão geral do Armazenamento, consulte [Visão geral do Armazenamento](/help/workfront-fusion/set-up-and-manage-workfront-fusion/use-workfront-storage/storage-overview.md).

Os arquivos no Adobe Storage podem ter várias versões.

## Exibição do histórico de versões

1. No Workfront Fusion, clique em **Armazenamento** na navegação à esquerda.
1. Navegue até o repositório e a pasta que contém o arquivo cujas versões você deseja exibir.
1. Selecione um arquivo e clique em **&quot;Versões&quot;** na barra de ações.
Um painel **Histórico de Versões** é aberto.
As versões são listadas como as mais recentes primeiro, cada uma mostrando:
   * Número da versão
   * Data
   * Um botão **Baixar**

   A versão atual (mais recente) está rotulada com um selo **&quot;atual&quot;**

Para baixar uma versão específica, consulte [Baixar uma versão específica](/help/workfront-fusion/set-up-and-manage-workfront-fusion/use-workfront-storage/download-files-from-storage.md#download-a-specific-version) no artigo Baixar arquivos do Armazenamento.
